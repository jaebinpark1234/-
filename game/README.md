# 밤하늘 드론쇼 (가제)

상자 맨 위의 드론 팩을 쇼 순서대로 하늘에 띄워 숨은 그림을 완성하는 한 손 퍼즐입니다.
웹 포털(Poki, CrazyGames)에 먼저 내고 안드로이드, iOS 순서로 갑니다.

## 문서

- [기획서](docs/GDD.md): 규칙, 난이도, 수익화, 홍보, 아트 방향
- [할 일 목록](docs/TASKS.md): 다른 AI에게 하나씩 맡기는 작업 단위
- [출시 절차와 비용](docs/LAUNCH.md): 스토어 등록비, 한국에서 필요한 신고
- [AI 작업 안내](AGENTS.md): 코드 구조와 규칙. 코딩 AI에게 먼저 읽힌다

## 실행

Node.js 22 이상이 필요합니다.

```bash
npm install
npm run dev
```

터미널에 나오는 주소(보통 http://localhost:5173)를 브라우저로 엽니다. 휴대폰 화면처럼 보려면 브라우저 개발자 도구의 모바일 보기를 켭니다.

## 지금 되는 것

- 메뉴 → 레벨 → 결과 흐름, 데일리 쇼와 연속 기록
- 자동 생성 레벨(1레벨부터 끝없이), 레벨마다 풀 수 있는지 확인
- 그림 맞히기, 부스터 2종, 막혔을 때 이어하기
- 광고 자리(지금은 테스트용 가짜 광고)
- 한국어/영어

그림 12개, 아트와 소리는 아직 코드로 그린 임시 상태입니다.
