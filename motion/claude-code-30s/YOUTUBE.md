## 파일

| 파일 | 용도 |
|---|---|
| `out/claude-code-30s_16x9.mp4` | 일반 영상 (1920×1080, 60fps) |
| `out/claude-code-30s_shorts.mp4` | 쇼츠 (1080×1920, 60fps) |
| `out/thumbnail.png` | 일반 영상 썸네일 (1280×720) |

30초짜리라 같은 이야기를 두 번 올릴 수 있다. 가로 영상은 채널 본편이나 재생목록용으로, 세로 영상은 쇼츠 피드용으로 올린다. 쇼츠 버전은 마지막 장면이 첫 장면과 같은 검은 화면으로 이어져서 반복 재생돼도 어색하지 않다.

## 제목 후보

1. 새벽 2시, 테스트 47개가 깨졌다 | Claude Code 애니메이션
2. 범인은 `=` 하나였다 (Claude Code 30초 애니)
3. 버그는 맡기고 잠은 자자 — Claude Code

쇼츠 제목은 짧게 쓴다. 예: `범인은 = 하나였다 #ClaudeCode`

```
새벽 2시, 테스트 47개가 깨졌다.

이 영상은 팬이 만든 애니메이션이며 Anthropic 공식 영상이 아닙니다.
```

## 올릴 때 챙길 것

- 일반 영상은 30초라 최종 화면(엔드스크린) 요소를 넣을 수 있는 구간이 짧다. 마지막 4초 엔딩 카드 위에 구독 버튼 요소 하나만 얹는다.
- 고정 댓글에 "여러분의 새벽 2시 버그는 뭐였나요?" 같은 질문을 남기면 댓글이 붙기 쉽다.
- 영상 속 Claude 마스코트는 원작 로고를 따라 그린 것이 아니라 새로 만든 캐릭터다. 그래도 제목과 설명에 공식 영상처럼 보이는 표현은 쓰지 않는다.
- 배경음과 효과음은 `audio.py`로 직접 합성해서 저작권 문제가 없다. 폰트는 Pretendard와 JetBrains Mono(둘 다 SIL OFL)다.
